# แจ้งเตือน Discord เมื่อมีไฟล์ใหม่ใน Google Drive

สคริปต์ Google Apps Script (`Code.gs`) จะตรวจโฟลเดอร์
[Aqua-Tots Drive](https://drive.google.com/drive/folders/17TwLCihdnOmxw03F2joAI-EcPpwSBwub)
ทุก 10 นาที แล้วส่งข้อความเข้า Discord เมื่อ

- 🆕 มีไฟล์ใหม่ รวมถึงไฟล์ที่ย้ายเข้ามาและไฟล์ในโฟลเดอร์ย่อย
- ✏️ มีการแก้ไขไฟล์เดิม ปิดได้โดยตั้ง `NOTIFY_UPDATES = false`

ใช้ฟรี ไม่ต้องมีเซิร์ฟเวอร์ บัญชีที่ติดตั้งต้องมีสิทธิ์อย่างน้อย "ผู้ดู" โฟลเดอร์

## 1. สร้าง Discord Webhook

1. ใน Discord ไปที่ห้องที่ต้องการรับแจ้งเตือน → **Edit Channel** (รูปเฟือง)
2. **Integrations** → **Webhooks** → **New Webhook** ตั้งชื่อ (เช่น Aqua-Tots Drive)
3. กด **Copy Webhook URL** เก็บไว้ ห้ามแชร์ต่อ เพราะใครมี URL นี้ก็โพสต์เข้าห้องได้

## 2. ติดตั้งสคริปต์

1. เปิด <https://script.google.com> ด้วยบัญชี Google ที่เข้าโฟลเดอร์ได้ → **New project**
2. ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจาก `Code.gs` → กด **Save**
3. ใส่ Webhook URL วิธีใดวิธีหนึ่ง
   - **ง่ายสุด:** แก้บรรทัด `const DISCORD_WEBHOOK_URL = '';` (บรรทัดที่ 18) ใส่ URL ใน `''` แล้ว Save
   - **ปลอดภัยกว่า:** เมนูซ้าย **Project Settings** → **Script Properties** → **Add script property**
     Property `DISCORD_WEBHOOK_URL`, Value = URL (ไม่ต้องแก้โค้ด และ URL ไม่ติดไปถ้าแชร์โค้ด)
4. กลับไปหน้า **Editor** เลือกฟังก์ชัน `setup` ด้านบน แล้วกด **Run**
5. ครั้งแรก Google จะขออนุญาต → **Review permissions** → เลือกบัญชี → **Advanced** → **Go to … (unsafe)** → **Allow**
   (ขึ้นคำเตือนเพราะเป็นสคริปต์ที่เราสร้างเอง ไม่ได้ผ่านการรับรองจาก Google)

ถ้าสำเร็จ จะมีข้อความ "✅ เริ่มติดตามโฟลเดอร์ Google Drive แล้ว" เด้งใน Discord
ไฟล์ที่มีอยู่แล้วจะไม่ถูกแจ้งซ้ำ แจ้งเฉพาะไฟล์ที่เพิ่ม/แก้หลังจากนี้

## การปรับแต่ง

แก้ค่าที่ส่วน `ตั้งค่า` บนสุดของ `Code.gs` แล้วรัน `setup` ใหม่

| ค่า | ความหมาย |
| --- | --- |
| `CHECK_EVERY_MINUTES` | ความถี่การตรวจ (1, 5, 10, 15, 30 นาที) |
| `NOTIFY_UPDATES` | `true` แจ้งเมื่อมีการแก้ไขไฟล์เดิมด้วย, `false` แจ้งเฉพาะไฟล์ใหม่ |
| `INCLUDE_SUBFOLDERS` | รวมไฟล์ในโฟลเดอร์ย่อย |

- **หยุดแจ้งเตือน:** รันฟังก์ชัน `stop`
- **ดูประวัติ/ข้อผิดพลาด:** เมนูซ้าย **Executions**

## ข้อจำกัด

- แจ้งช้าสุดประมาณรอบการตรวจ (ค่าเริ่มต้น 10 นาที) ไม่ใช่ทันที
- ไฟล์ Google Docs ที่มีคนกำลังพิมพ์ จะถูกแจ้ง "มีการแก้ไข" ได้หลายรอบ ถ้ารำคาญให้ตั้ง `NOTIFY_UPDATES = false`
- ไม่แจ้งตอนลบไฟล์
