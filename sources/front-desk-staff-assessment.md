<!-- chunk: มาตรฐานการประเมิน (ความถี่ตามระดับ) การมาปฏิบัติงาน และ Core Values -->

แบบประเมินพนักงานต้อนรับ (AT-FDS) ประเมินได้ 3 ครั้ง (#1 #2 #3) โดยผู้ประเมินแต่ละครั้งกรอกชื่อและตำแหน่ง แต่ละหัวข้อมีช่อง Note

**Performance Standards (ความถี่การประเมินตามระดับ)**
- **Candidate:** 1–7 วัน
- **Beginner:** 1 เดือน — ประเมินทุกสัปดาห์
- **Intermediate:** 1–3 เดือน — 2 ครั้งต่อเดือน
- **Advanced:** 4–6 เดือน — 1 ครั้งต่อเดือน

**การมาปฏิบัติงาน**
- มาตรงเวลา และแต่งกายถูกต้อง
- ยิ้มแย้ม พร้อมบริการลูกค้าด้วยคุณภาพเหนือความคาดหวัง
- กล่าวต้อนรับลูกค้าแบบ Aqua-Tots
- ทำงานตามใบรายการเปิดและปิดโรงเรียนได้ถูกต้อง
- บอกลาโดยเรียกชื่อนักเรียนหรือผู้ปกครอง
- ปิดบัญชีรายวัน (cash to day) ได้ถูกต้อง

**ปฏิบัติตาม Core Values ของ Aqua-Tots**
- จดจำได้ครบทั้ง **7 ข้อ**
- อธิบายความหมายของแต่ละข้อได้เหมาะสม
- ยกตัวอย่างสถานการณ์จริงได้
- Q&A แก้ปัญหาโดยใช้ Core Values ได้เหมาะสม

<!-- chunk: การประเมินการทัวร์ A.Q.U.A และการบอก 7 โซนของโรงเรียน -->

**การทัวร์ A.Q.U.A**
- **Approach:** ต้อนรับลูกค้าภายใน **3 วินาที** เมื่อเข้าโรงเรียน โดยเดินออกนอกเคาน์เตอร์
- **Question:** ถามชื่อ อายุ และประสบการณ์เรียนว่ายน้ำ
- บอกชื่อตัวเอง ประวัติ Aqua-Tots และเลเวลที่น้องจะได้เรียน
- บอกโซนครบทั้ง **7 โซน**:
  1. บริเวณขายของ: อธิบายอุปกรณ์การสอนที่เหมาะกับเลเวล
  2. บริเวณนั่งรอผู้ปกครอง: โซฟาสีแดงนั่งรอดูเด็ก ๆ อย่างสบาย
  3. Aqua-Card Bin: แสดงตัวอย่างการ์ดและอธิบายประโยชน์
  4. บริเวณสระ: อธิบายระบบน้ำ โซน ชี้คลาส และบอกว่าสอนอะไรอยู่
  5. ห้องอาบน้ำเปลี่ยนชุด: สิ่งอำนวยความสะดวก และจุดฟีดแบค
  6. บริเวณที่เล่นเด็ก สิ่งอำนวยความสะดวก และ Wifi ฟรี
  7. จบทัวร์ที่เคาน์เตอร์
- ถามคำถามที่เหมาะสมระหว่างเดิน
- เรียกชื่อนักเรียนทุกครั้งเมื่อพูดถึง
- เสนอขายคอร์สเรียนต่อ

<!-- chunk: การประเมินการขายออนไลน์ และการขาย A.Q.U.A -->

**การขายออนไลน์**
- สอบถามประวัติการเรียนว่ายน้ำ (ดำน้ำเก็บของ ลอยคว่ำ ลอยหงาย กระโดดจากขอบสระกลับเข้าหาฝั่ง)
- ประเมินเลเวลได้ถูกต้อง และให้รายละเอียดของเลเวลนั้น
- ชักชวนทุกทางให้มาทดลองเรียน และหาตารางทดลองเรียนได้
- คอนเฟิร์มวันทดลองเรียน พร้อมส่งการเตรียมตัวก่อนมาเรียน
- ลงตารางนัด ทำ Aqua Card เก็บในแฟ้มตามวันที่

**การขาย A.Q.U.A**
- ถามเป้าหมายในการพามาเรียน เพื่อรู้ความต้องการ
- แนะนำคอร์สเรียน **2 วันต่อสัปดาห์**
- **Unite:** เสนอบริการ Aqua-Tots ให้ตรงความต้องการ
- **Action:** แนะนำคอร์สและโปรโมชั่น
- ปิดการขาย แจ้งจำนวนเงินที่ต้องชำระ
- ถามวันที่สะดวก พร้อมคอนเฟิร์มตารางเรียนประจำ
- อธิบายกฎระเบียบ ให้เซ็นเอกสารรับทราบ และมอบ Welcome Packet
- ใส่ข้อมูลในฟอร์มผู้ปกครองใหม่ และทำ Aqua Card
- เก็บข้อมูลการจ่ายเงินแบบ Recurring
- ถามว่ามีคำถามอะไรไหม

<!-- chunk: การประเมินการใช้โปรแกรม POS การแจกประกาศนียบัตร และเหตุการณ์ไม่คาดคิด -->

**การใช้โปรแกรม POS**
- สร้าง new clients / new services / ใส่ชื่อนักเรียนในคลาส
- check in / bulk enroll / confirm attendance
- ปริ้นรายชื่อนักเรียน (rosters) และกดซื้อได้ถูกต้อง
- **ย้ายตารางนักเรียน:** ย้ายครั้งเดียว = ออกเมคอัพแล้วคอนเฟิร์มด้วยเมคอัพ / ย้ายตลอดไป = remove ตลอดไป ใส่ชื่อในเวลาใหม่ แล้ว bulk enroll
- **ลงคลาสชดเชย** (การเรียนชดเชยยกเลิกไม่ได้)
- **ทำดร็อปนักเรียน:** ถามปัญหา หาวิธีแก้ แจ้งวันสิ้นสุด ส่งแบบฟอร์มดร็อป
- cancel class / change schedule / filter calendar
- เช็คคอร์สคงเหลือ / make up คงเหลือ
- refund / hold และ remove hold
- settings plans, passes, merchandise / advanced setting / reporting

**การแจกประกาศนียบัตรและการขึ้นเลเวลใหม่**
- เตรียมใบประกาศ Swim Level Certificate
- แสดงความยินดีกับนักเรียนที่จบเลเวลแบบ Aqua-Tots
- ถ่ายรูปจบเลเวลกับ **Ollie the Otter**
- หาตารางเรียนใหม่ใน FDHQ และย้ายตาราง คอนเฟิร์มเวลาเลเวลใหม่ และทำ Aqua-Card
- บอกนักเรียนและผู้ปกครองว่ารูปจะขึ้นจอ TV และโพสต์ลงเพจ Facebook
- บอกจุดประสงค์การเรียนในเลเวลถัดไป

**การปฏิบัติเมื่อเกิดเหตุการณ์ไม่คาดคิด**
- คุยกับผู้ปกครองด้วยท่าทางปกติ และเน้นว่าเด็ก ๆ อยู่ในความปลอดภัย
- คอนเฟิร์มเวลาปิดสระกับโค้ชในสระ
- ติดต่อครอบครัวที่เหลือในวันนั้นเรื่องการเปลี่ยนเวลาเรียนหรือปิดสระ
- ต้อนรับลูกค้าที่เข้ามาตามปกติด้วยบริการขั้นสูงสุด

**หมวด C.A.R.E sale** — ประเมินด้วยหัวข้อเดียวกับ C.A.R.E. Coaching Form (Connect, Assess, Recommend, Enroll) แบบ Y/N
