# ชุดคำถามทดสอบ Chatbot (Aqua-Tots Knowledge Base)

ใช้ทดสอบว่า chatbot ค้นหา chunk ได้ถูก ตอบตรงเนื้อหา และแนบลิงก์อ้างอิงถูกเอกสาร

**วิธีให้คะแนนแต่ละข้อ**

| ผล | เกณฑ์ |
| --- | --- |
| ✅ ผ่าน | คำตอบมีข้อเท็จจริงในคอลัมน์ "คำตอบที่คาดหวัง" ครบ และอ้างอิงเอกสาร (`doc_id`) ถูก |
| ⚠️ บางส่วน | ตอบถูกบางส่วน หรือถูกแต่อ้างอิงผิดเอกสาร |
| ❌ ไม่ผ่าน | ตอบผิด แต่งข้อมูลขึ้นเอง หรือไม่แนบแหล่งอ้างอิง |
