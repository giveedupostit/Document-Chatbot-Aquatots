# SOP ระบบการทำงาน (Pike13 / Digipay / ATU): วิธี Refund และการโยกคอร์ส (เปลี่ยนผู้เรียน) ใน Pike13

**การ Refund มี 2 แบบ**
- **Refund as account credit** — เก็บยอดเงินไว้ในชื่อลูกค้า เพื่อนำไปซื้อคอร์สอื่นใหม่
- **Refund offline as cash** — คืนเงินลูกค้า หรือใช้กรณีปิดยอดเกินแล้วต้องลบทิ้ง

**ใช้เมื่อ:** ซื้อผิดยอดเงิน, ตั้งวันเริ่มเรียนผิด, ซื้อ Plan ผิด

**ขั้นตอน**
1. คลิกที่ชื่อผู้ปกครอง > แถบฟังก์ชันขวามือ เลื่อนหา **Bills**
2. คลิกแถบ **Closed** แล้วเลือก Bill ที่ต้องการ Refund
3. คลิก **Refund Payment**
4. กรณี account credit ให้แก้ตัวเลขยอดที่ต้องการดึงออก แล้วเลือก **Refund as account credit**
5. คลิก **cancel plans**
6. เลือกส่ง/ไม่ส่งอีเมลให้ลูกค้า (**กรณีโรงเรียนผิดพลาดเอง ไม่ควรส่งอีเมลให้ลูกค้า**)
7. คลิก **Process Refund**

**กรณีพิเศษ: ซื้อแพลนให้แม่ (ลืมเลือกชื่อลูก) หรือโยกคลาสให้พี่/น้องเรียนแทน**
1. คลิกที่ Plans แล้วเลื่อนลงสุดถึงแถบ **Participants**
2. คลิก **Change** แล้วเปลี่ยนเป็นชื่อลูก หรือชื่อพี่/น้องอีกคนได้เลย
