# Job Description - Aquatic Manager (AM) ผู้จัดการฝ่ายสระ: หน้าที่ AM ด้านทรัพยากรบุคคลและการพัฒนาทีม

**ด้านทรัพยากรบุคคล**
- ดูแลการจ้างงานและฝึกอบรมพนักงานทางน้ำใหม่
- จัดการและบันทึกการลงโทษทางวินัย พูดคุยหาทางออกกับ GM และ Owner และลงโทษตามความเหมาะสม
- รักษาและจัดทำเอกสารรับรองพนักงานทางน้ำ (ขอใบ Cert กับต่างประเทศ)
- ช่วย GM จัดตารางพนักงานทางน้ำ นับชั่วโมงสอนของโค้ช และปรับให้สอดคล้องกับกะที่ต้องเปิด — ชั่วโมงสอนโค้ช **ไม่เกิน 20–25 ชั่วโมง/สัปดาห์**
- ช่วย GM ทบทวนผลงานรายปีและรายไตรมาส ติดตามและพัฒนาเฟสโค้ช และอัปเดต GM ทุกสัปดาห์
- จัดการการเข้างานและความครอบคลุมกะ ตรวจสอบใบบันทึกเวลาและส่งให้ GM
- ช่วย GM ในการ onboarding พนักงานทางน้ำ (ถ้าจำเป็น)

**ด้านการพัฒนาทีม**
- สร้างบรรยากาศทีมและวัฒนธรรม Aqua-Tots ที่ส่งผลเชิงบวก
- ประเมินพนักงานทางน้ำ (KPI) ตามตารางที่กำหนด
- ดูแลให้โค้ชทุกคนให้ฟีดแบคผู้ปกครองและนักเรียนได้อย่างมืออาชีพ
- พบพนักงานที่มีประสิทธิภาพต่ำเป็นประจำ โค้ชที่พัฒนาช้าให้เรียกคุยบ่อย ๆ อย่าปล่อยปละละเลย
- ตรวจสอบและสร้างแผนปฏิบัติการจากรายงาน Deck Supervisor
- จัดประชุมพนักงานทางน้ำรายเดือนและ In-Service ทุกเดือน
- ประชุม Master Instructor และ Deck Supervisor ทุกเดือน
- ช่วย GM จัดกิจกรรม Team Building ทุก 3 เดือน
