# Job Description - Aquatic Manager (AM) ผู้จัดการฝ่ายสระ: สรุปตำแหน่ง AM และหน้าที่ด้านบริการลูกค้าและการขาย

**สรุปงาน:** Aquatic Manager (AM) เป็นผู้นำและผู้จัดการพนักงานทางน้ำ (WSI) ทุกคน เพื่อรักษา Core Values และมาตรฐานแบรนด์ Aqua-Tots อย่างสม่ำเสมอ

**ภารกิจ (Our mission):** ช่วยลดอัตราการจมน้ำของเด็กทั่วโลก ผ่านการสอนว่ายน้ำให้เด็กรู้สึกปลอดภัยและมั่นใจในน้ำ ตามมาตรฐานหลักสูตร Aqua-Tots และบริการลูกค้าที่เป็นเลิศในสภาพแวดล้อมที่ปลอดภัยและเป็นมิตร

**ด้านบริการลูกค้าและการขาย**
- ดูแลให้พนักงานทางน้ำปฏิบัติตาม Core Values ทุกคนเข้าใจและตอบคำถามลูกค้าได้ดี
- รักษาการมีส่วนร่วมและความพึงพอใจของลูกค้าในน้ำ ให้ลูกค้าชอบแบรนด์
- ให้ความรู้ลูกค้าเรื่องโปรแกรม Learn to Swim และตอบคำถามเรื่องหลักสูตรได้ครบถ้วน
- ช่วย GM จัดการตารางเรียนในระบบ POS และดูแลตารางโค้ช
- จัดการการประเมินในน้ำเพื่อพัฒนาโค้ช ประเมิน KPI (ถ้าไม่มั่นใจ ส่งวิดีโอให้ HQ ร่วมประเมินได้)
- ช่วย GM ตอบสนองปัญหาบริการลูกค้าและฟีดแบคที่เกี่ยวกับผู้สอนหรือหลักสูตร (โซเชียลมีเดีย อีเมล ตัวต่อตัว) และแนะนำ GM เรื่องเนื้อหาหลักสูตรที่จะลงโซเชียล
- ติดตามการถอนตัวของนักเรียนที่เกี่ยวกับหลักสูตรหรือผู้สอน และตามนักเรียนที่ลาออกกลับมา (AM Report)
- ติดตามความก้าวหน้าของนักเรียนทุกคนในโรงเรียน รวมถึงนักเรียนที่ไม่มีความก้าวหน้า (เช็คได้ที่ E-mail info)
- ช่วย GM ดูแลให้ WSI ทุกคนมีคุณภาพและเข้าใจงานฝั่งน้ำครบถ้วน
