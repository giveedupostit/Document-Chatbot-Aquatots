# ระเบียบการแข่งขัน Swim Meet 2025 (สาขาทวีวัฒนา): กำหนดการ Swim Meet 2025 และระยะการแข่งขันแต่ละเลเวล

**กำหนดการ** (เวลาอาจคลาดเคลื่อน นักกีฬาต้องพร้อมเสมอ)

| เวลา | กิจกรรม |
| --- | --- |
| 09.00 | เปิดลงทะเบียน |
| 09.15 | เลเวล 1–2 รายงานตัว |
| 09.15–10.00 | กิจกรรมเลเวล 1–2 |
| 09.45 | เลเวล 3 รายงานตัว |
| 09.45–10.30 | แข่งขันเลเวล 3 |
| 10.15 | เลเวล 5 รายงานตัว |
| 10.15–11.00 | แข่งขันเลเวล 5 |
| 11.00–12.00 | แจกเหรียญรางวัล (ช่วงเช้า) |
| 12.00–12.45 | พักเที่ยง |
| 12.45 | เลเวล 4 รายงานตัว |
| 12.45–13.30 | แข่งขันเลเวล 4 |
| 13.15 | เลเวล 6 รายงานตัว |
| 13.15–14.00 | แข่งขันเลเวล 6 |
| 13.45 | เลเวล 7–8 รายงานตัว |
| 13.45–14.30 | แข่งขันเลเวล 7–8 |
| 14.30 | กิจกรรม Special และแจกเหรียญรางวัล (ช่วงบ่าย) |

**ระยะการแข่งขัน**
- เลเวล 1–2: เต็มสระ (กิจกรรมร่วมคลาสและเข้าฐานต่าง ๆ ในน้ำ)
- เลเวล 3–4: แนวขวางของสระ **8 เมตร**
- เลเวล 5–6: แนวยาวของสระ **14 เมตร**
- เลเวล 7–8: แนวยาวไปกลับ **28 เมตร**
