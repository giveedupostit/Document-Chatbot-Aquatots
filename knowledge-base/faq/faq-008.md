# คำถามที่พบบ่อย (Q&A AT): FAQ: เมื่อไหร่น้องจะว่ายน้ำเป็น และต้องเรียนกี่ครั้ง/กี่วันต่อสัปดาห์

**ถาม: เมื่อไหร่น้องถึงจะว่ายน้ำเป็น**
ตอบ: การเรียนว่ายน้ำเหมือนเรียนเปียโนหรือเทควันโด เน้นการจดจำผ่าน muscle memory คือทำซ้ำบ่อย ๆ จนกล้ามเนื้อเคยชิน และต้องเรียนสม่ำเสมอ โรงเรียนแนะนำให้เรียน **จบเลเวล 6** น้องจะว่ายได้ทั้ง 3 ท่า (ฟรีสไตล์ กรรเชียง กบ) อย่างมั่นใจ เอาตัวรอดในน้ำได้ และรักการว่ายน้ำในระยะยาว

**ถาม: เรียนกี่ครั้ง / กี่เดือน ถึงจะว่ายน้ำเป็น**
ตอบ: น้องแต่ละคนพัฒนาต่างกัน มี 4 ปัจจัย:
1. **อายุ** — มีผลต่อการรับรู้ การสื่อสาร และสรีระในการทำสกิล
2. **สมาธิ** — ถ้าน้องไม่นิ่ง ยุกยิก ไม่เข้าใจ จะเรียนรู้ช้าลง
3. **ความชอบ** — ถ้าชอบเล่นน้ำอยู่แล้ว จะเรียนรู้ไวขึ้น
4. **การมาเรียนสม่ำเสมอ** — ยิ่งมาบ่อย สมองและกล้ามเนื้อยิ่งจดจำเร็วขึ้น

**ถาม: ควรเรียนกี่วันต่อสัปดาห์เพื่อพัฒนาได้ดีที่สุด**
ตอบ: แนะนำเรียนครั้งละ 30 นาที **2–3 ครั้งต่อสัปดาห์** การเรียนระยะสั้นแบบต่อเนื่องช่วยให้จดจำและทำทักษะได้ดี

**ถาม: ได้เรียนกับโค้ชคนเดิมทุกครั้งไหม**
ตอบ: โรงเรียนตั้งใจให้น้องเรียนกับโค้ชคนเดิมทุกครั้ง แต่บางกรณีอาจเปลี่ยนโค้ช เช่น โค้ชลาป่วย พักร้อน โรงเรียนจะรีบแจ้งผู้ปกครองทันที และโค้ชทุกคนผ่านการอบรม สอนด้วยมาตรฐานเดียวกัน
