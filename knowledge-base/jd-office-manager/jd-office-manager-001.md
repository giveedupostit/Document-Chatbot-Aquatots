# Job Description - Office Manager (OM) ผู้จัดการสำนักงาน: สรุปตำแหน่ง Office Manager (OM) และหน้าที่ความรับผิดชอบ

**แผนก:** Operations (การดำเนินงาน)

(ตัวอย่างรายละเอียดงานที่ต้องปรับตามความต้องการของโรงเรียน แนะนำให้เปิดตำแหน่งนี้เมื่อโรงเรียนมีนักเรียนลงทะเบียนสม่ำเสมอถึง **800 คน**)

**สรุปงาน:** ผู้จัดการสำนักงานช่วยผู้จัดการทั่วไป (GM) เป็นผู้นำและจัดการพนักงานแผนกต้อนรับ ในการรักษาค่านิยมหลักของ Aqua-Tots และมาตรฐานแบรนด์ ภารกิจคือการให้บทเรียนว่ายน้ำคุณภาพสม่ำเสมอตามมาตรฐานหลักสูตร และการบริการลูกค้าที่เป็นเลิศในสภาพแวดล้อมที่ปลอดภัยและเป็นมิตร

**ประเภทตำแหน่ง:** เต็มเวลา วันและชั่วโมงแตกต่างตามความต้องการและฤดูกาลของโรงเรียน

**รายงานต่อ:** GM / Owner

**ขอบเขตความรับผิดชอบ**
- เช็คตารางใน Pike13 และ notification ของ Pike13
- เช็คเด็ก in-water และโทรคอนเฟิร์ม
- โทรติดตามลูกค้าที่มา in-water แล้ว และโทรหาลูกค้าที่สนใจทั้งหมด
- พูดคุยและตอบคำถามลูกค้า ดูแลติดตามปัญหาต่าง ๆ
- จัด in-service (อบรม) ให้ Front Desk และประเมินการพาทัวร์ของพนักงาน
- ปิดยอด เคลียร์บิล
- ตรวจสอบ report เช่น เด็กลงแพลนถูกไหม ใครยังไม่ชำระเงิน (อย่าให้เกินวันที่ 5) การปิดบิลถูกต้องไหม ใคร unpaid
- เช็คเด็กที่ติดอยู่ในเลเวลเกิน 6 เดือน และเช็คว่าใครมีเมคอัพเยอะ
- สั่งสินค้า (แจ้ง GM ก่อน)
- ตรวจเช็คฟอร์มและเอกสารต่าง ๆ
- อัปเดตคอนเทนต์ Facebook ดูแล LINE / Facebook คิดคอนเทนต์หรือแคมเปญใหม่และนำเสนอ
- ติดตามการทำงานของ staff และประชุมกับ GM
- ตรวจความเรียบร้อยการเปิด-ปิดโรงเรียน กลิ่น และน้ำยาฆ่าเชื้อ
- ตรวจความสะอาดทั้งหมดในโรงเรียน กระจกทั้งหมด เคาน์เตอร์ และ lobby
- วัดไข้เด็ก
- เช็คอีเมลของสาขาและสายที่ไม่ได้รับ (missed calls)
- ดูแลบอร์ดเด็กจบเลเวล

(รายละเอียดงานผู้จัดการสำนักงาน / เมษายน 2025)
