# Swim School Daily Task List Form (รายการงานประจำวันของโรงเรียน): งานปิดยอดบัญชีประจำวัน (Accounting Closing) และส่วนที่ทีมผู้นำต้องตรวจ

**Accounting Closing Staff Member Tasks**
1. นับเงินในเครื่องคิดเงิน
2. นำเงินสดออกและตรวจยอดสำหรับนำฝากธนาคาร
3. กรอกใบนำฝากตามจำนวนที่จะฝาก
4. ใส่ใบนำฝาก เงินสด และเช็คลงซอง เขียนวันที่และชื่อย่อผู้ดำเนินการบนซอง แล้วปิดผนึก
5. นำซองและลิ้นชักเงินสดไปเก็บในพื้นที่ปลอดภัยที่กำหนดในห้องผู้จัดการ
6. พิมพ์ End of Day Report

**เอกสารที่ต้องเย็บติดกันเป็นชุดปิดโรงเรียน:** Swim School Daily Task List, Swim School Daily Sales Tracker, สำเนาสีเหลืองของ Bank Deposit Slip, End of Day Report, ใบเสร็จบัตรเครดิตและ Batch Report, Gift Certificate แบบกระดาษที่ได้รับ — วางชุดเอกสารทั้งหมดบนโต๊ะผู้จัดการ

**ส่วนที่ทีมผู้นำ (Leadership) ต้องทำ**
- ตรวจยอดเงินสด/เช็คที่จะนำฝาก
- ตรวจความถูกต้องของ End of Day Report
- กรอก Daily Sales Journal Form
- นำเงินฝากธนาคาร และเย็บใบเสร็จการฝากติดกับชุดเอกสาร
- ตรวจ Daily Task List ว่าพนักงานทำครบ และติดตามงานที่ค้าง
- จัดเก็บชุดเอกสารใน Monthly Accounting Bundle ตามวันที่
