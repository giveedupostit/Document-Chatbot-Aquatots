# Swim School Daily Task List Form (รายการงานประจำวันของโรงเรียน): งานเปิดโรงเรียน (Open the School) และช่วงคลาสเช้า (AM Swim Lessons)

แบบฟอร์มรายการงานประจำวัน กรอกวันที่และวัน แต่ละช่วงให้พนักงานลงชื่อและลายเซ็น

**เปิดโรงเรียน (Open the School)**
- ปิด/ยกเลิกระบบสัญญาณกันขโมย (Alarm)
- เปิดไฟ และเปิดเพลง
- ตั้งเครื่องปรับอากาศให้อุณหภูมิเหมาะสม
- จัดเก้าอี้ โต๊ะ และแผ่นรองต่าง ๆ
- กวาดเศษสิ่งสกปรกหน้าโรงเรียน และทำความสะอาดขอบหน้าต่าง
- ตรวจสินค้า Retail ให้พอ เป็นระเบียบ และสะอาด
- นับเงินในลิ้นชักแคชเชียร์
- พิมพ์รายชื่อนักเรียนคลาสเช้า (AM Class Roster) ไปติดที่ห้องสระ
- เติมของใน Treasure Chest ขนม และ Coffee Bar
- ปลดล็อกประตูทางเข้าด้านหน้า
- เตรียมพร้อมสำหรับนักเรียนวันแรก (1st Day) และ IWE
- ตรวจข้อความเสียง (VM) และอีเมล
- ตรวจ SMS และ Tasks ใน BrandBot / HubSpot
- ตรวจอีเมล School Info (Lead Forms / ลงทะเบียนออนไลน์ / Parent Portal)
- ตรวจใน Pike13 ว่ามีคลาสใดลงทะเบียนเกินจำนวนหรือไม่

**ช่วงคลาสเช้า (AM Swim Lessons)**
- ยืนยันการเข้าเรียนของนักเรียน
- ตรวจความปลอดภัย – ถูพื้นบริเวณประตูทางออก
- สร้างความสัมพันธ์กับครอบครัว (อย่าลืมทำ 10-Minute Check-In)
- ตรวจ เติมของ และทำความสะอาดห้องน้ำ
- ตรวจ VM อีเมล SMS และ Tasks ใน BrandBot/HubSpot และอีเมล School Info
- แจ้งฝ่ายบริหารเรื่องข้อกังวลหรือปัญหาของลูกค้าที่พบระหว่างกะ
- โทรติดต่อลูกค้า Lead เบื้องต้น
