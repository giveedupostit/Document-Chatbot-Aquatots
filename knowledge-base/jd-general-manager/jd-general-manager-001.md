# Job Description - General Manager (GM) ผู้จัดการทั่วไป: สรุปตำแหน่ง GM และหน้าที่ด้านลูกค้า การขาย และการบริการ

**Department:** Operations (ตัวอย่างรายละเอียดงานที่ต้องปรับตามความต้องการของโรงเรียน)

**หน้าที่โดยรวม:** General Manager (GM) เป็นผู้นำและบริหารจัดการพนักงานทุกฝ่ายในโรงเรียน ให้การดำเนินงานเป็นไปตาม Core Values และมาตรฐานแบรนด์ Aqua-Tots พันธกิจคือมอบการเรียนว่ายน้ำคุณภาพสม่ำเสมอตามมาตรฐานหลักสูตร พร้อมบริการลูกค้าที่เป็นเลิศ ในสภาพแวดล้อมที่ปลอดภัย เป็นมิตร และอบอุ่น

**ประเภทงาน:** Full-time ค่าจ้างรายเดือน วันและเวลาทำงานขึ้นกับความต้องการของสาขา

**รายงานต่อ:** เจ้าของสาขา (Owner), เจ้าของแฟรนไชส์ และ/หรือ Regional Manager

**หน้าที่ด้านลูกค้าและการขาย**
- ดูแลให้พนักงานทุกคนปฏิบัติตาม Aqua-Tots Core Values ในทุกการทำงานและการสื่อสารกับลูกค้า
- กำกับดูแล Aquatic Manager (AM) และ Office Manager (OM) (ถ้ามี)
- สร้าง Aqua-Tots Experience เพื่อรักษาการมีส่วนร่วมและความพึงพอใจของลูกค้า
- ดูแลความปลอดภัยของโรงเรียนสำหรับพนักงานและลูกค้า
- ให้ความรู้ลูกค้าเรื่องโปรแกรม Learn to Swim และแนะนำ/จำหน่ายคอร์สให้ตรงความต้องการ
- กำกับดูแลประสบการณ์ลูกค้าผ่านแพลตฟอร์มเทคโนโลยี
- ดูแล Front Desk ในการติดตามและเปลี่ยน Lead เป็นการสมัครเรียน
- กำกับการจัดการปัญหาบริการลูกค้า รวมถึงเคสที่ต้องยกระดับ
- ติดตามกรณีลูกค้าขอหยุดเรียนหรือถอนตัว
- รักษามาตรฐานคุณภาพการสอน การบริการ และความสะอาด
- กำหนดเป้าหมายยอดขาย และวางระบบแรงจูงใจให้พนักงาน
