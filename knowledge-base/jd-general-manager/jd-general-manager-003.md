# Job Description - General Manager (GM) ผู้จัดการทั่วไป: คุณสมบัติและใบรับรองที่ต้องมีสำหรับตำแหน่ง GM

**คุณสมบัติขั้นต่ำ**
- ปริญญาตรีหรือเทียบเท่า
- ใบอนุญาตขับขี่รถยนต์ที่ถูกต้อง
- ทำงานตามเวลาที่ยืดหยุ่นได้
- ประสบการณ์บริหารหรือจัดการอย่างน้อย 2–3 ปี
- ทักษะบริการลูกค้า งานธุรการ การสื่อสารพูดและเขียนดีมาก การเขียนรายงาน สรุปข้อมูล และนำเสนอ

**คุณสมบัติที่พิจารณาเป็นพิเศษ**
- ปริญญาตรี
- ประสบการณ์ทำงานกับเด็ก
- ประสบการณ์ด้านการขายหรือบริหารงานขาย

**ใบรับรองที่จำเป็น**
- Aqua-Tots Front Desk Staff (AT-FDS)
- Basic Aqua-Tots Water Safety Instructor (AT-WSI)
- CPR และ First Aid

(General Manager Job Description / May 2025)
