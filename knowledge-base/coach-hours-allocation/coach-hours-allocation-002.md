# การจัดสรรชั่วโมงลงน้ำของโค้ช กรณีโค้ชลา / ขาด: หลักการบริหารชั่วโมงสอน ผู้รับผิดชอบ และกรณีพิเศษ

**หลักการบริหารชั่วโมงสอน**
- ใช้โค้ชประจำให้เกิดประโยชน์สูงสุดก่อนใช้โค้ช Part-time
- กระจายชั่วโมงอย่างเหมาะสมและเป็นธรรมระหว่างโค้ชประจำ
- ไม่ให้โค้ชประจำเกิน 25 ชั่วโมงสอนต่อสัปดาห์
- ดูชั่วโมงเดิมของแต่ละคนก่อนจัดเพิ่ม
- ไม่ให้ชั่วโมงเพิ่มกับคนใดคนหนึ่งต่อเนื่อง ถ้ายังมีโค้ชประจำคนอื่นที่ชั่วโมงต่ำกว่าและรับได้
- โค้ช Part-time เป็นทางเลือกเมื่อบริหารชั่วโมงโค้ชประจำไม่พอ

**ผู้รับผิดชอบ**
- **Aquatic Manager (AM) / ผู้จัดตารางสอน:** ตรวจจำนวนโค้ชที่ลา/ขาด ตรวจชั่วโมงสอนแต่ละคน และจัดสรรตามหลักเกณฑ์
- **General Manager (GM):** กำกับให้เป็นไปตามนโยบาย และพิจารณากรณีต้องใช้โค้ช Part-time เพิ่ม

**กรณีพิเศษ:** หากจัดสรรตามแนวทางไม่ได้ เช่น โค้ชประจำสอนไม่ได้หรือมีเหตุฉุกเฉิน AM/GM ปรับได้ตามความเหมาะสม โดยคำนึงถึงคุณภาพการสอน ความปลอดภัยของนักเรียน และความต่อเนื่องของบริการเป็นสำคัญ

**การทบทวน:** ทบทวน SOP อย่างน้อยปีละ 1 ครั้ง หรือเมื่อมีเหตุการณ์สำคัญ

(การจัดสรรชั่วโมงลงน้ำของโค้ชกรณีมีโค้ชลา ขาด / August 2026)
