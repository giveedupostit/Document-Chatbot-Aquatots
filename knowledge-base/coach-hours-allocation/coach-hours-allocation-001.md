# การจัดสรรชั่วโมงลงน้ำของโค้ช กรณีโค้ชลา / ขาด: วัตถุประสงค์และลำดับการจัดสรรชั่วโมงสอนเมื่อโค้ชลา/ขาด (โค้ชประจำก่อน แล้วจึง Part-time)

**Department:** Operations

**วัตถุประสงค์:** กำหนดแนวทางจัดสรรชั่วโมงลงน้ำของโค้ชให้เป็นมาตรฐานเดียวกันทุกสาขา กรณีโค้ชประจำลา ขาด หรือปฏิบัติหน้าที่ไม่ได้ โดยคำนึงถึงจำนวนชั่วโมงทำงานที่เหมาะสมและการบริหารต้นทุนของสาขา

**ขั้นที่ 1: จัดสรรให้โค้ชประจำ (Full-Time Coach) ก่อน**
- โค้ชประจำสอนได้ **ไม่เกิน 25 ชั่วโมงต่อสัปดาห์**
- ให้ชั่วโมงเพิ่มกับโค้ชที่มีชั่วโมงสอนน้อยกว่าก่อน
- ต้องไม่ทำให้โค้ชคนใดเกิน 25 ชั่วโมงต่อสัปดาห์ และพิจารณาความเหมาะสมของตารางงาน

**ตัวอย่าง:** มีโค้ชประจำ 4 คน ลา 1 คน ชั่วโมงเดิม Coach A = 20, B = 18, C = 15, D = 12 ชั่วโมง ต้องทดแทน 8 ชั่วโมง → ให้ Coach D และ Coach C ก่อน โดยไม่ให้ใครเกิน 25 ชั่วโมง

**ขั้นที่ 2: พิจารณาโค้ช Part-time** เมื่อ
- โค้ชประจำทุกคนได้รับชั่วโมงตามความเหมาะสมแล้ว และ
- การเพิ่มให้โค้ชประจำจะเกิน 25 ชั่วโมง/สัปดาห์ หรือไม่มีโค้ชประจำรับได้ และ
- ยังมีชั่วโมงสอนที่ต้องมีผู้รับผิดชอบ
