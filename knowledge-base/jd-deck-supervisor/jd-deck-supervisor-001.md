# Job Description - Deck Supervisor (หัวหน้าดูแลขอบสระ): สรุปตำแหน่ง Deck Supervisor และหน้าที่ความรับผิดชอบ

**Department:** Operations

**หน้าที่โดยรวม:** Deck Supervisor ดูแลความปลอดภัย คุณภาพ และความราบรื่นของการเรียนว่ายน้ำ เหมาะกับผู้ที่รับผิดชอบสูง มีประสบการณ์สอนว่ายน้ำ และมีภาวะผู้นำ กำกับการเรียนแต่ละช่วงเวลา ดูแลสภาพแวดล้อมสระให้ปลอดภัย และสนับสนุนทั้งผู้สอนและนักเรียน

**ประเภทงาน:** Part-Time ค่าจ้างรายชั่วโมง อย่างน้อย 1 กะต่อสัปดาห์

**รายงานต่อ:** Aquatic Manager และ/หรือ Lead on Duty

**หน้าที่ความรับผิดชอบ**
- ดูแลความปลอดภัยของนักเรียนทุกคน บังคับใช้กฎความปลอดภัยอย่างเคร่งครัด
- ปฏิบัติตาม Aqua-Tots Core Values
- **เข้างานก่อนเวลาเรียนอย่างน้อย 30 นาที** เพื่อเตรียมอุปกรณ์การสอน
- สนับสนุนและช่วยเหลือผู้สอนตามความจำเป็น
- ร่วมเปิดและปิดสระในแต่ละวัน
- รักษาคุณภาพการสอนโดยประเมินผู้สอน AT-WSI
- นำการประชุมก่อนเริ่มกะ (Pre-shift Meeting)
- กรอก **Deck Supervisor Daily Log** และส่งให้ Aquatic Manager
- ดูแลให้ทุกคลาสเริ่มและจบตรงเวลา โดยรักษา **ระยะเวลาเรียน 27 นาทีต่อคลาส**
- ตอบคำถามผู้ปกครองเกี่ยวกับหลักสูตร
- ช่วยดูแลเด็กที่ร้องไห้หรืออารมณ์ไม่พร้อมเรียน
- รายงานข้อร้องเรียนเกี่ยวกับการเรียนให้ Aquatic Manager
- เป็นพี่เลี้ยง (Peer Mentor) ให้ผู้สอน
- ทักทายนักเรียนด้วยชื่อเมื่อมาถึง และพานักเรียนที่มาสายไปยังคลาส
- บริหารกรณีปิดสระ จัดงานทำความสะอาดช่วงไม่มีคลาส และดูแลการตรวจวัดสารเคมีในสระ
- กรณีเกิดเหตุเล็กน้อย ปฏิบัติตามขั้นตอน สื่อสารกับผู้ปกครอง และรายงาน Lead on Duty และ/หรือ Aquatic Manager
