# Fast Track SOP (คอร์สเรียนเร่งรัด Fast Track): วิธีการสอน Fast Track และการเลื่อนระดับ

**วิธีการสอน**
ผู้สอนประเมินความสามารถว่ายน้ำของเด็กแต่ละคนตั้งแต่วันแรก และกำหนดเป้าหมายเฉพาะสำหรับแต่ละคน การจำแนกให้ถูกว่าเป็นระดับเริ่มต้น ระดับกลาง หรือระดับสูง สำคัญมาก เพื่อปรับการสอนให้เหมาะและดึงศักยภาพเด็กได้เต็มที่ จากนั้นสอนเหมือนคลาสกลุ่มทั่วไปตามลำดับทักษะที่กำหนด

**การเลื่อนระดับใน Fast Track**
- นักเรียนเลื่อนไปเลเวลถัดไปได้ภายในคอร์ส Fast Track หากทำทักษะทั้งหมดของเลเวลเริ่มต้นได้อย่างสม่ำเสมอ
- เมื่อจบคอร์ส ผู้สอนแจ้งผู้ปกครองว่าควรลงเรียนเลเวลใดต่อ (Fast Track รอบถัดไป หรือคลาสรายสัปดาห์)
- ผู้สอนควรแจ้งฝ่ายต้อนรับล่วงหน้าถ้ามีนักเรียนเลื่อนระดับ เพื่อเตรียมใบประกาศนียบัตรได้ทัน

(Fast Track SOP / March 2025)
