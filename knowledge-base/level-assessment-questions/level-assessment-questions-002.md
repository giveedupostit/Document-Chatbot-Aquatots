# แนะนำคำถามการประเมินเลเวล (Level 1–8): การประเมินเลเวล 4 และเลเวล 5

**Level 4 (อายุ 4 ปีขึ้นไป)**
1. น้องเป่าบับเบิ้ล (ฟองอากาศ) ได้หรือไม่
2. น้องกระโดดลงสระแล้วเตะขากลับไปที่ขอบสระได้หรือไม่
3. น้องว่ายท่าฟรีสไตล์ได้หรือไม่
4. น้อง "เงยหน้าขึ้นหายใจ" ระหว่างว่ายโดยไม่มีคนช่วยได้หรือไม่
5. น้องพลิกตัวคว่ำหรือหงาย และพลิกกลับได้หรือไม่
6. น้องเตะขาข้ามสระขณะลอยหงายได้หรือไม่
7. น้องว่ายน้ำโดยไม่สวมแว่นตาได้หรือไม่

\*\*\* หากตอบว่า **ไม่** เด็กจะอยู่ใน **Level 4**

**Level 5 (อายุ 4 ปีขึ้นไป)**
1. เวลาหายใจตอนว่ายฟรีสไตล์ น้องหันศีรษะไปด้านข้างหรือยกศีรษะขึ้น
2. น้องว่ายท่ากรรเชียงข้ามสระได้ถูกต้องหรือไม่
3. น้องเตะขาท่ากบได้ถูกต้องหรือไม่
4. น้องทำท่าแขนท่ากบได้ถูกต้องหรือไม่
5. น้องหยิบของจากก้นสระขึ้นมาได้เองหรือไม่

\*\*\* หากตอบว่า **ไม่** เด็กจะอยู่ใน **Level 5**
